## Cómo publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub (puede ser público o privado).
2. Sube **toda** esta carpeta (index.html + images/ + videos/).
3. Ve a **Settings → Pages**.
4. En "Source" elige la rama `main` (o `master`) y carpeta `/ (root)`.
5. Guarda. En 1-2 minutos tendrás el enlace tipo:
   `https://tu-usuario.github.io/nombre-del-repo/`
